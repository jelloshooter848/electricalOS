# Reference entry style guide

- Write for an electrician on a job site reading a phone. Short sentences.
- Explain what the section requires and why it matters in the field.
- Never paste code text. If you cannot explain it without quoting, leave the
  entry out and cite the section only.
- Numbers (percentages, amps, distances) are fine to state.
- Include the section number exactly as printed in that edition, and set
  `priorSection` when the number changed between editions.
- Field notes are for common inspector calls, exceptions people miss, and
  interactions with other sections.
- Each entry is reviewed against the adopted edition by a second person before
  release. Record the review in docs/data-verification.md.
